# Live Judgment 需求文档

> 本文档是需求的单一可信源。状态：初稿（2026-08-15 与用户确认的需求口径）。

## 背景与目标

B 站直播间存在大量使用自动化工具发言的账号：独轮车（同一句话反复刷屏）与自动融入（模仿正常观众跟风发言）等行为严重影响正常观众观感。本项目做一个运行于 B 站直播页面的油猴脚本，帮助观众与房管**识别、标记、追溯、处置**这些账号。

## 功能需求

### F1 弹幕接入

- 接入直播间弹幕流，获取每条弹幕的发送者 uid、昵称、内容、时间戳。
- 备选通道：页面聊天区 DOM 监听（MutationObserver）或 B 站直播弹幕 WebSocket 协议；选型在首个 spec 中拍板。

### F2 异常行为检测

基于**内容**与**发送时序**两类信号，对发言用户打分/归类：

| 编号 | 行为 | 检测信号 |
|---|---|---|
| D1 | 独轮车（定时复读） | 同一用户发送间隔恒定且不低于约 1 秒；文本反复出现；列表式轮播 |
| D2 | 不可见字符规避 | 弹幕含 U+00AD 等零宽/不可见字符；剔除不可见字符后与历史弹幕完全相同（强信号，正常输入不产生此类字符） |
| D3 | ~~拦截重发~~（已并入 D2，2026-08-16 拍板：被吞弹幕第三方不可观测，可观测特征与 D2 完全重合） | — |
| D4 | 自动融入（跟风复读） | 从不发起刷屏，但某文本被多人重复形成趋势后极短时间（约 1 秒内）必跟发；两次参与间隔呈稳定冷却特征；房间弹幕越快其参与越稀疏 |
| D5 | 语义改写复读 | 同一用户反复发送语义相同、措辞微变的弹幕（LLM 润色特征） |
| D6 | 语音强相关发言 | 弹幕与主播语音内容呈秒级强相关或近逐字转写（置信度低，作为辅助信号，可能后置实现） |
| D7 | 拉黑失效 | 已被当前用户拉黑/屏蔽的账号仍持续在聊天区活跃发言（依赖平台侧可观测性，可能后置实现） |

- 检测为**概率性标记**：输出「类别 + 置信度 + 证据」，允许误报，不做静默处罚。
- D1–D4 为首期实现范围；D5–D7 后置。

### F3 用户标记展示

- 在直播间聊天区，对被判定异常的用户做可视标记（如彩色角标/高亮），鼠标悬停显示判定类别与置信度。
- 标记风格可由用户配置（颜色、是否高亮整条弹幕）。

### F4 弹幕记录与违规档案

- 本地持久化记录直播间弹幕（IndexedDB），保留可配置的时长/条数。
- 对被标记用户可查看其弹幕历史：时间、原文、命中了哪条检测规则。
- **违规档案跨场次积累**（2026-08-16 拍板）：每次判定落一条事件记录（uid、昵称、规则、置信度、证据、roomId、主播名、时间），跨场次/跨房间在本地累积；查看某用户时可见其在各主播直播间的历史违规记录（主播名异步解析并缓存）。
- **人工确认名单**（2026-08-16 拍板）：用户复核后可手动把人加入/移出本地名单，持久、跨房间生效，入场即标；自动检测不写该名单。
- 徽章触发口径：仍以「本场证据 + 人工名单」为准；自动积累的历史档案用于展示与复核，不单独触发徽章（防止行为改变后的误标残留）。

### F5 快捷处置（依赖登录态与权限）

- 对被标记用户提供一键操作：
  - **举报**：调用 B 站直播举报接口；
  - **拉黑**：加入当前用户黑名单；
  - **禁言**：加入房间禁言（需当前用户为该房间房管/主播，无权限时隐藏或置灰）。
- 所有处置动作执行前需用户确认；接口失败时明确提示。

### F6 屏蔽词过滤

- 读取/同步直播间已有屏蔽词列表，并支持用户自建本地屏蔽词（含正则）。
- 命中屏蔽词的弹幕：本地隐藏（默认）或高亮提示；命中用户可选择计入检测证据。

### F7 配置与数据

- 油猴脚本标准设置面板：检测开关（按规则）、灵敏度/阈值、标记样式、屏蔽词管理、数据保留策略。
- 所有数据仅存本地（IndexedDB / 脚本存储），不上传任何服务器。

## 非目标（明确不做）

- 不做主动发送弹幕、不做任何自动化发言功能。
- 不做**联网**共享名单（避免隐私与滥用问题）。本地积累与人工名单已拍板要做，见 F4。
  （旧规则「不做跨直播间追踪/共享名单」→ 新规则：跨房间**本地**积累档案与人工名单做，联网共享不做。——2026-08-16 用户拍板）
- 不逆向、不绕过 B 站风控；仅使用页面已授权的接口与数据。
- 首期不做：D6 语音相关检测、D7 拉黑失效检测、账号信用分体系。

## 约束

- 产物为 Tampermonkey / Violentmonkey 油猴脚本，作用于 B 站直播页面。
- 技术栈：Bun + Vite + TypeScript。
- 合规底线：检测仅做标记与提示，所有处置动作由用户手动确认触发。
