# 002 检测引擎（F2：D1/D2/D4）设计规格

- **日期**：2026-08-16
- **状态**：已定稿
- **来源**：`docs/requirements.md` F2；spec 001（弹幕接入）

## 背景与目标

实现纯 TypeScript、无 DOM 依赖的检测引擎：消费 `DanmakuSource` 的弹幕事件流，按 D1（独轮车复读）、D2（不可见字符规避）、D4（自动融入跟风）三类规则产出「用户 → 类别 + 置信度 + 证据」的判定结果，供后续标记渲染（F3）消费。成功标准：合成事件流单元测试覆盖三类规则的命中与防误报，`bun test` / typecheck / lint / build 全绿。

## 设计

### 文本归一化（normalize.ts）

- 剔除不可见字符集：U+00AD（软连字符）、U+200B–U+200F（零宽系列）、U+202A–U+202E（方向控制）、U+2060–U+2064、U+FEFF（BOM）。
- 归一化文本 = 剔除不可见字符 + 去首尾空白 + 折叠连续空白。所有跨消息比对一律用归一化文本；原始文本保留用于展示和 D2 取证。

### 滑动窗口（window.ts）

- **用户窗口**：每 uid 一个双端队列，保留最近 10 分钟且最多 100 条事件，超时/超量即淘汰。
- **全局窗口**：全房间事件队列，保留最近 60 秒，供趋势统计。
- 全部为会话内存，页面刷新即清空；持久化属于 F4，不在本期。

### 规则

**D2 不可见字符规避（逐条即时判定）**

- 原始文本含上述不可见字符 → 记证据（字符码位列表）。正常输入法不产出此类字符，单条命中即置信度**高**。
- 允许误报豁免：暂不豁免，上线后观察（见待决 2）。

**D1 独轮车复读（按用户累计判定）**

对用户窗口做三项检查，命中即记证据：

1. **复读**：同一归一化文本在窗口内出现 ≥ 3 次；
2. **固定节拍**：最近 ≥ 4 个发送间隔全部 ≥ 900ms（B 站服务端限速约 1s，自动化工具通常贴着限速跑）且变异系数 < 0.15；
3. **轮播**：归一化文本序列呈长度 2–6 的周期循环且重复 ≥ 2 轮。

命中 1 项置信度**中**，≥ 2 项置信度**高**。

**D4 自动融入跟风（趋势跟随统计）**

- **趋势资格**：某归一化文本在全局窗口的最近 15 秒内，被 ≥ 3 个不同 uid 发送且总条数 ≥ 3。记录资格达成时刻 tq 与达成前的发送者集合（早期参与者）。
- **跟风事件**：tq 之后 10 秒内发送该文本且不在早期参与者集合中的用户，记一次跟风（含延迟 = 发送时刻 − tq）。
- **用户画像**：累计跟风次数、作为早期参与者的次数、平均跟风延迟。
- 判定：跟风 ≥ 3 次且早期参与 0 次且平均延迟 ≤ 2 秒 → 置信度**中**；跟风 ≥ 5 次且其余条件同上 → 置信度**高**。
- 跟风事件必须来自**已形成的趋势**（防误报核心：三个人同时聊同一话题不等于刷屏趋势，资格门槛已含人数与密度要求）。

### 引擎接口（engine.ts / verdict.ts）

```ts
type RuleId = 'D1' | 'D2' | 'D4'
type Confidence = 'medium' | 'high'

interface RuleHit { rule: RuleId; confidence: Confidence; evidence: string[] }
interface UserVerdict { uid: number; uname: string; hits: RuleHit[]; updatedAt: number }

interface DetectionEngine {
  ingest(event: DanmakuEvent): void
  getVerdict(uid: number): UserVerdict | undefined
  onVerdict(cb: (v: UserVerdict) => void): () => void // 仅在判定新增/升级时回调
}
```

阈值集中在 `DetectConfig` 常量对象，先拍默认值，真实直播间数据校准后调整（见待决 2）。

### 目录结构

```
src/lib/detect/
  engine.ts       编排：消费事件、驱动规则、聚合判定、回调
  window.ts       用户/全局滑动窗口
  normalize.ts    不可见字符剔除与文本归一化

  rules/
    d1-repeat.ts
    d2-invisible.ts
    d4-bandwagon.ts
test/detect/      bun test 合成流用例
```

### 测试用例（先红后绿）

- 复读机流（同文本 ×5，间隔恒定 1.0–1.1s）→ D1 高置信；
- 含 U+00AD 的单条消息 → D2 高置信；
- 3 个用户把某文本刷成趋势、第 4 人 1 秒内跟发 × 3 个趋势 → 第 4 人 D4，前 3 人无判定；
- 正常对话流（多人多话题、间隔随机 2–30s）→ 无任何判定（防误报）；
- 轮播序列（A B C A B C）→ D1 轮播证据。

## 明确不做（out of scope）

- D3（拦截重发）：按拍板决策 4 并入 D2，不单独建规则。
- D5（语义改写复读）、D6、D7。
- 标记渲染（F3）、持久化（F4）、屏蔽词联动（F6）、设置面板（F7）。
- 阈值自动调优、跨场次用户画像。
