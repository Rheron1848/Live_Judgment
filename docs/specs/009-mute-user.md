# 009 按用户屏蔽（本地隐藏指定用户的弹幕）设计规格

- **日期**：2026-08-18
- **状态**：待评审
- **来源**：2026-08-18 用户实播使用中提出；spec 007（F6 屏蔽词，架构复用）

## 背景与目标

F6 解决了「按关键词隐藏」，缺「按用户隐藏」：不想看到某人的全部弹幕，仅自己浏览器生效。与 watchlist（观察标记，不隐藏）和 F5 拉黑（服务器端真实生效）定位不同，这是纯本地的轻量处置。

## 已拍板决策

| # | 决策 | 拍板人 | 日期 |
|---|------|--------|------|
| 1 | 新增按用户屏蔽，本地隐藏其弹幕，可解除 | 用户 | 2026-08-18 |
| 2 | 分「当前直播间名单」和「跨直播间名单」两级（同 F6 屏蔽词的房间/全局结构） | 用户 | 2026-08-18 |
| 3 | 命名约定：本地动作一律带「本地」前缀（本功能 UI 名为「本地屏蔽此人」），与官方屏蔽/拉黑/禁言区分 | 用户 | 2026-08-18 |

## 设计要点

- **存储**：IDB 升 v3，新增 object store `usermutes`：`{id?, uid, uname, roomId}`（roomId=0 表全局），增量迁移同 v2 模式。
- **判定**：`isMuted(uid, currentRoomId, entries)` 纯函数——全局名单 ∪ 本房间名单命中即隐藏（与 blockwords matcher 同构）。
- **隐藏**：复用 `lj-hidden` / `hideElement`；`reapplyHiding` 扩展为同时按「文本命中屏蔽词」或「uid 命中屏蔽名单」判定。
- **入口**：面板用户页加「屏蔽此人发言」按钮（本房间/全局二选一）；已在名单则显示「解除屏蔽」。屏蔽词页签加「屏蔽的用户」分组列表，可解除。
- 被屏蔽用户的弹幕照常进引擎与落库（沿用 spec 007 决策 5：屏蔽 ≠ 放过违规）。
- 持久化不可用时降级会话级内存（同既有降级风格）。

## 明确不做（out of scope）

- 与 F5 拉黑联动（本地屏蔽 ≠ 官方黑名单）。
- 屏蔽时长/临时屏蔽。
- 屏蔽名单导入导出。

## 待决（OPEN）

- 无。

## 验收标准

- `isMuted` 纯函数测试（全局/本房间/其他房间不命中/解除后恢复），先红后绿。
- typecheck / lint / `bun test test/` / build 全绿。
- CDP 真实直播间：屏蔽某 uid → 其弹幕消失、他人不受影响；解除 → 恢复。
